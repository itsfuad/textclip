# textclip

Wrap paragraphs to terminal width while preserving word boundaries.

Small, dependency-light C99 / libc utility. Original implementation and history generated for a retrospective development exercise.

## Build

`make && make test`

Run `./textclip 35 examples/sample.txt`. Uses only the standard C library.

## Maintenance

Version 0.2 includes a small usability improvement and additional coverage for everyday workflows. No network dependencies are required.
